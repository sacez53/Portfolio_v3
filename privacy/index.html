Politique de confidentialité

Cette page décrit ce qui se passe lorsque vous consultez le portfolio ou envoyez un message.

Formulaire de contact

Sacha Guitter traite les messages envoyés depuis le portfolio pour répondre aux demandes. À l’envoi du formulaire, votre navigateur transmet vos nom et prénom, votre adresse e-mail, le sujet et le texte de votre message à EmailJS. Ce service achemine le message vers la boîte e-mail de Sacha Guitter. Une confirmation peut aussi être envoyée à votre adresse.

Pour connaître le traitement des données par ce prestataire, consultez la politique de confidentialité d’EmailJS.

Consultation du portfolio

La version publiée sur sacez53.github.io est hébergée par GitHub Pages. Sur l’accueil, le navigateur charge la bibliothèque Leaflet depuis unpkg et le script EmailJS depuis jsDelivr. Lorsque la carte s’affiche, le navigateur demande des tuiles à OpenStreetMap. Ces requêtes transmettent des données techniques telles que l’adresse IP aux services qui les reçoivent.

Les conditions de ces services sont détaillées dans la déclaration de confidentialité de GitHub et la politique de confidentialité d’OpenStreetMap.

Demandes relatives à vos données

Pour poser une question sur le traitement ou demander l’accès, la rectification ou l’effacement de données liées à un message, écrivez à sachaguitterphoto@gmail.com. La CNIL explique ces droits et les démarches à suivre.
