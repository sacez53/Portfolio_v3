À propos de Project Manager

Gestionnaire éditorial officiel du portfolio de Sacha Guitter.

Project Manager Desktop

Version 2.3.0 · Standalone Windows Application

Conçu pour accompagner le flux de travail photographique et graphique de Sacha GUITTER (étudiant en BUT MMI à l'IUT de Laval et photographe animalier). Cette application permet d'éditer, d'indexer et d'ordonner tous les projets éditoriaux sans ligne de commande.

⌨️ Raccourcis Clavier :

  • Ctrl + N : Créer un nouveau projet
  • Ctrl + F : Focus sur la barre de recherche
  • Échap : Fermer la modale ou la vue active
  • Ctrl + S : Sauvegarder dans le formulaire

🛠️ Technologies Embarquées :

Node.js Single Executable Application (SEA), Chromium App Runtime, REST Native Engine, Modern CSS Grid & Vanilla JS.
